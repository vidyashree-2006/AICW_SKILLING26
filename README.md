# SkillSphere MVP

A free, browser-only personalized learning MVP. No database, paid API, or API key is required.

## Run in VS Code

### Option 1 — simplest
Open `index.html` in a browser.

### Option 2 — recommended
Install the VS Code **Live Server** extension, then right-click `index.html` → **Open with Live Server**.

## Included
- Student onboarding with localStorage
- Level 0 first; progressive unlocking
- Personalized examples from the student's interest
- Text / Visual / Audio / Code modes
- Adaptive "I don't understand" explanation
- Doubt chatbot (local demo logic)
- Mini quizzes and demonstrated skill progress
- Skill growth and industry-demand prototype graphs
- Daily activity
- Skill gap
- Next-topic flow
- Course completion and "Choose For Me" recommendations
- Safe controlled code demonstrations
- Responsive mobile-friendly UI

## Demo flow
Use:
- Name: Demo Student
- Hobby: Cricket
- Interest: Cricket
- Course: Python
- Career Goal: AI Engineer
- Level: Beginner

Then open Learn. **Level 0 starts first.** Complete a lesson/quiz to unlock the next level.

## Note
Industry demand values are illustrative prototype values. Audio uses the browser's built-in speech synthesis. The coding area intentionally does not execute arbitrary Python.
